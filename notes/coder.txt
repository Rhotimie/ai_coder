    - WAYS TO ENHANCE CLAUDE ABILITIES
        - MCP: Connect Claude Code to someone else’s tools
            - Massive ecosystem, Highly flexible, Mature marketplaces

            - Easy way to use Tools written by someone else
            - Easy way to connect LLMs with Tools
            - It’s the interface, not the tools themselves
            - It’s not efficient - overuse can fill up the context window and lead to poor results, even with recent context use improvements

            references:
                - https://registry.modelcontextprotocol.io/
                    - official mcp website
                - https://github.com/modelcontextprotocol/servers
                - **https://mcp.so/**
                - **https://glama.ai/mcp**

                - verify before use on github, check extensive documentation

            installations: 
                - claude mcp add context7 -- npx -y @upstash/context7-mcp --api-key {api_key}
                - claude mcp add massive -e MASSIVE_API_KEY={MASSIVE_API_KEY} -- uvx --from git+https://github.com/massive-com/mcp_massive@v0.10.0 --with "mcp<2" mcp_massive

                - claude mcp list

                - claude mcp remove context7
                - claude mcp remove massive

        - Skills: Add expertise & capabilities
            - Context efficiency, Simple setup, Strong results

            - Skills are implemented with a “File System Architecture”
            - Skills is simpler and more context efficient and might replace MCP
            - Introduced after MCP; primarily focused on instructions as Markdown files rather than Tools
            - “Progressive disclosure” reduces context overhead
            - Also supports running scripts locally; this provides an interesting alternative type of tools
            - Not as flexible and powerful as Tools
            - Skills feel like the more compelling solution for Claude Code, but this is evolving
            - they are just a bunch of markdown files and scripts

            -references:
                - https://github.com/anthropics/skills
                    - https://github.com/anthropics/skills/tree/main/skills
                - https://www.skills.sh/
                    - made by vercell
                    - has agent-browser skills

            - installation
                - npm install -g agent-browser
                - agent-browser install
                - npx skills add https://github.com/vercel-labs/agent-browser --skill agent-browser

        -- Skills are implemented with a “File System Architecture”

        -- 3 levels of “Progressive Disclosure
            -- SKILL.md
                -- Metadata: Name + description: When should this skill be triggered?
                -- Instructions: Information with workflows, guidance, code snippets
            -- Other files
                -- Resources + Code: Info that can be accessed & scripts that can be run

        .claude
            skills
                my-great-skill/
                SKILL.md
                more_stuff_here_referenced_above.md
                and_more_stuff.md
                scripts/
                    scripts_in_any_language_with_instructions_above.py

        The script itself stays out of context
        This structure can be in your home directory (all projects) or project directory (project only)

            - The most simple
            - Best trade-offs of context and capability
